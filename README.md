# GoodPixel (Galaxy to Pixel 統合ユーティリティ)

Galaxy端末（Good Lock / One Hand Operation + / スマート選択 / エッジパネル / NotiStar 等）からGoogle Pixel（または他社Android端末）へ移行する際に、失われがちな**親指操作の快適性、情報収集スピード、大画面マルチタスク体験を1つのアプリで完全再現・強化するオールインワン常駐ユーティリティ**です。

---

## 🎯 開発の背景とコンセプト

Galaxyを長年愛用してきたユーザーが他社製Androidに乗り換えた際、最も大きな障壁となるのが「Good Lock（One Hand Operation +、NotiStar等）」の不在です。
本プロジェクトでは、複数のアプリを個別に入れるのではなく、**「1つの統合常駐サービス」**として設計・実装することで、以下のメリットを実現しています：

1. **タッチ判定の競合・誤爆ゼロ**: 画面端のジェスチャー判定とエッジパネルを1つのエンジンで管理。
2. **バッテリー消費・メモリ消費の最小化**: 常駐サービス（AccessibilityService、NotificationListenerService）を一元化。
3. **設定の一元管理**: Jetpack Composeによるモダンな設定画面で全機能をまとめて設定可能。

---

## 🚀 主要機能一覧

### 1. 画面端ジェスチャー（One Hand Operation + 完全再現）
画面両端（左右）から親指をスライドさせるだけで、各種システムアクションを即座に実行できます。

| 操作トリガー | 動作内容 | 備考 |
| :--- | :--- | :--- |
| **水平スワイプ (→ / ←)** | **戻る (Back)** | 親指が届く範囲で画面どこからでも戻る |
| **斜め上スワイプ (↗ / ↖)** | **全画面スクリーンショット** | ワンアクションで瞬時に撮影 |
| **斜め下スワイプ (↘ / ↙)** | **スマート選択 (SmartCapture)** | 画面フリーズ ＋ 矩形切り抜き即時保存 |
| **水平長押しスワイプ** | **クイックツール** | 音量・明るさ等のポップアップパネル |
| **斜め下長押しスワイプ** | **画面自動回転 ON/OFF** | システム設定をダイレクト切り替え |

- **長押し成立時の触覚フィードバック**: 350ms保持で2回目の「ブルッ」が鳴り、長押し成立が指先で直感的に分かります。
- **キーボード自動退避 (`moveKeyboard`)**: ソフトウェアキーボード（IME）が開くと、ハンドルが自動的にキーボード上端より上へ退避。**バックスペースキー（⌫）や確定キーへの干渉が一切ありません**。

---

### 2. スマート選択（SmartCapture / 矩形切り抜き即保存）
Instagramの写真やWeb記事の必要な箇所だけを、1秒で画像ファイルとして保存できます。

- **静止画フリーズ表示**: 斜め下スワイプした瞬間の画面を保持。
- **直感的な範囲指定**: 指で四角くドラッグして選択。
- **位置移動 ＆ サイズ変更**: 枠内ドラッグで移動、四隅・四辺の丸ハンドルで自在にリサイズ可能。
- **画面端マグネティックスナップ**: 画面の端（上下左右）に近づくと自動でカチッと端（0px）に吸着し、微小なハプティック振動が指先に伝わります。
- **位置ズレ・歪みゼロ**: ステータスバーやパンチホールを全画面貫通描画し、元画面と1ピクセルも狂わずに重なります。
- **即時保存**: 「✓ 写真を保存」をタップすると `Pictures/GoodPixel` フォルダへ高画質PNG保存。

---

### 3. エッジパネル（Edge Panel）
画面右端の手元上部に常駐する白い細身の半透明タブから、いつでもアプリランチャーを展開できます。

- **アプリランチャー**: よく使う主要アプリをワンタップで即座に起動。
- **全アプリ編集機能 (`EdgeAppPicker`)**: 端末内のすべてのアプリ（電卓・設定・Googleアプリ含む）から、お好みのアプリを追加・削除・並び替え可能（最大12個）。
- **ショートカット搭載**: NotiStar、スマート選択、クイックツールへも即アクセス。
- **ゲーム自動非表示機能**: ゲームアプリ起動時はエッジタブが自動で完全非表示（`GONE`）になり、ゲームプレイを一切邪魔しません。

---

### 4. NotiStar 代替機能（NotiLog / 完全時系列通知ログ ＋ 全文検索）
OS標準の通知欄のようにアプリごとにまとめず、**届いた順に1件ずつフラットに時系列蓄積**します。

- **バックグラウンド自動収集**: `NotificationListenerService` により全アプリの通知を受信してローカルSQLiteに永続化。
- **インクリメンタル全文検索**: アプリ名・タイトル・本文の部分一致で過去の通知を瞬時に検索可能。
- **ワンタップジャンプ**: 通知カードをタップすると、その通知の該当画面（`PendingIntent`）へ直接遷移。
- **履歴管理**: 不要な通知の個別削除・全消去に対応。
- **HOME画面からダイレクト起動**: ホーム画面のGoodPixelアイコンをタップすると直接「通知ログ」が開きます。画面右上の「⚙️」からいつでも設定画面へ遷移可能。
- **App Shortcuts対応**: アプリアイコン長押しから「通知ログ」「設定」をホーム画面に個別配置できます。

---

### 5. クイックツール（Quick Tools）
画面端からの「水平長押しスワイプ」で、親指の届く手元位置にポップアップする操作パネルです。

- **メディア音量スライダー**: 音量物理キーを押さなくても、画面上で親指を左右に滑らせるだけで音量を微調整。
- **画面の明るさスライダー**: 手元でスムーズに画面の明るさを調整。
- **ワンタップトグル**: 画面自動回転、フラッシュライト（懐中電灯点灯/消灯）、全画面スクショ、スマート選択、NotiStar起動。

---

### 6. アプリ内自動アップデート機能（GitHub Releases 連携）
設定画面から「🔄 更新確認」をタップするだけで、GitHub Releases APIと直接通信して新バージョンの有無をチェックできます。

- **ワンタップ更新**: 新しいリリースが公開されている場合、更新内容（Changelog）を確認し、「⬇️ 今すぐ更新」を押すだけで自動ダウンロード ＆ APKインストーラーが起動します。
- **再ダウンロード対応**: すでに最新版が適用されている場合でも、必要に応じて最新APKの再ダウンロード・再インストールが可能です。
- **権限ガイダンス**: 提供元不明のアプリのインストール許可（`REQUEST_INSTALL_PACKAGES`）が必要な場合も、分かりやすいガイダンスとワンタップで設定画面へ誘導します。

## 🛠️ 技術スタック & アーキテクチャの工夫

- **言語**: Kotlin
- **UIフレームワーク**: Jetpack Compose (Material 3)
- **常駐サービス**:
  - `AccessibilityService`（最上位オーバーレイ、ジェスチャー判定、グローバルアクション実行、前面アプリ検知）
  - `NotificationListenerService`（通知の傍受・インメモリキャッシュ）
- **ローカルデータベース**: SQLite (`SQLiteOpenHelper`) による超軽量・高速な通知永続化
- **主要な技術的ハイライト**:
  - `WindowManager.LayoutParams.TYPE_ACCESSIBILITY_OVERLAY`: Android OS標準の「戻る」矢印ジェスチャーより上位レイヤーでタッチイベントを100%掌握。
  - `LAYOUT_IN_DISPLAY_CUTOUT_MODE_SHORT_EDGES`: ディスプレイカットアウト（カメラノッチ）やステータスバーを完全に貫通し、1080×2410の物理画面ピクセルと完全等倍表示を実現。
  - `moveKeyboard` アルゴリズム: `AccessibilityWindowInfo.TYPE_INPUT_METHOD` をリアルタイム監視し、キーボード展開時はオーバーレイの座標系を上方にシフト退避。
  - `QUERY_ALL_PACKAGES` & `MATCH_ALL`: Android 11以降のパッケージ可視性制限をクリアし、端末内の全インストール済みアプリを完全走査。

## 📋 必要なシステム権限

アプリの初回起動時、設定画面から以下の権限を許可してください：

| 権限 | 用途 |
| :--- | :--- |
| **ユーザー補助 (Accessibility Service)** | 画面端のスワイプ判定、戻る/スクショの実行、画面キャプチャの取得、ゲーム起動検知 |
| **他のアプリの上に重ねて表示 (Overlay)** | 画面端の透明タッチハンドル、エッジパネル、クイックツール、クロップ画面の表示 |
| **通知へのアクセス (Notification Listener)** | NotiStar機能としての過去通知の収集・保存・検索 |
| **システム設定の変更 (Write Settings)** | 画面自動回転のダイレクト切り替え |
| **カメラ (Camera)** | クイックツールからのフラッシュライト（懐中電灯）点灯制御 |

## 💻 ビルド & インストール手順

### 前提環境
- macOS / Linux
- JDK 17 (`JAVA_HOME`)
- Android SDK 34 / 36

### ビルドコマンド
```bash
export ANDROID_USER_HOME=/Users/yohei/Library/Android/user_home
export JAVA_HOME=/opt/homebrew/opt/openjdk@17
export PATH=$JAVA_HOME/bin:$PATH

# デバッグAPKのビルド
./gradlew assembleDebug
```

### 実機インストール（Pixel接続時）
```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```
